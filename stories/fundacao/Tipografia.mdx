<Secao titulo="Regras de uso">
<Callout>
Os estilos são compostos: não monte um texto empilhando tamanho, peso e altura de linha soltos. Se nenhum estilo cobre o caso, peça um novo estilo ao Design em vez de criar um valor local.

Use `title-*` para cabeçalhos de página e seção, `headline` para títulos de cartão, `body` para leitura e `caption-*` para legendas, rótulos e dados auxiliares. Os estilos `display-*` e `large-title` ficam para páginas de destaque.
</Callout>
